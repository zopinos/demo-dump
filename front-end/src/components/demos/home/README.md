# demo-dump

Hello, and welcome to Demo Dump!

Demo Dump arose from a need to have a home for my different smaller visual projects. So, if I have an idea to create something visual and interactable, I can include it here. Usually these will probably be something that can be done in the browser environment, but if not, other visual documentation (images, gifs?) could be provided here. For now, the list isn't that filled, but hopefully it will grow as time goes on.

The list of demos is in a chronological order, newest demo at the bottom of the list. Each demo view will have some descriptions and explanations about the project in this box / README associated to the project.
