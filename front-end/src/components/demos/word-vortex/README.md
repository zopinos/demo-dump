# Word Vortex

Word Vortex was the first demo I had in mind when creating demo-dump. I was fascinated by the fact that you could move text elements in the browser with CSS (with animation), so I wanted to create something that utilized that. A tornado of words seemed to be visually interesting in my head. After creating the demo, the effect isn't maybe as prominent as I pictured it in my head, but I still like it.

I'm also interested in visual illusions, but the motion aftereffect happened by accident. I wasn't supposed to create that and after creating the demo, I was a little worried that the demo will create some discomfort and nausea, but I hope it isn't that bad. Furthermore, I think the forewarning makes it cautious enough.
