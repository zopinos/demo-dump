# Drag N Throw

Drag N Throw was born as I wanted to start to learn about making more graphics based things on the browser. I thought that something where you could drag and throw simple shapes would be simple enough. Previously, I have liked UI where you can pick stuff up with the mouse, as well as games where you can carry physics object in front of you. Additional interactions are usually nice, so the ability to throw the physics object makes the interactions more satisfying, I think.
